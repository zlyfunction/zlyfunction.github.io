# Answers, in graphics language

Generated by `experiments/tables.py` from `results/survey.json`.

A holonomy signature is a set of cone angles (all multiples of `pi/2`)
together with the cross-field rotations along a homology basis.  By the
Reduction Lemma the rotations only matter through the subgroup of `Z_4`
they generate together with the cone angles, so each row below is a
complete case, not an example.

Range surveyed: genus [0, 1, 2, 3], at most 4 cones,
orders bounded by 8.

## Genus 0

5 cases in range; 5 realized by an explicit square-tiled surface; 0 unrealizable; 0 not decided by the quoted literature.

**Rule: always realizable.**  On the sphere the holonomy is determined by the cone angles, and Troyanov's theorem gives the metric, so quadrangulability never fails.

## Genus 1

36 cases in range; 34 realized by an explicit square-tiled surface; 2 unrealizable; 0 not decided by the quoted literature.

**Rule: realizable except the cases below**, plus the cone-free case: a torus with no cones is realizable only with trivial holonomy.  `docs/genus1.md` proves this list is complete for every number of cones, not just the surveyed range.

| cone angles | cross-field holonomy | why |
|---|---|---|
| pi, 3pi | every holonomy is a multiple of pi, some one is exactly pi | Q(1,-1) -- divisor c1 - c2 is never principal on an elliptic curve |
| 3/2 pi, 5/2 pi | some loop has holonomy an odd multiple of pi/2 | divisor c1 - c2 with c1 != c2 is never principal on an elliptic curve (equivalently: no nonzero 1-torsion point) |
